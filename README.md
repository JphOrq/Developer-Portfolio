# Joseph Portfolio

A lightweight multi-page personal portfolio built with plain HTML, CSS, and JavaScript.

## Pages
- `index.html` — Home
- `about.html` — About
- `projects.html` — Projects
- `tesda-project.html` — TESDA-related project case study
- `contact.html` — Contact

## Folders
- `css/style.css` — all styling and design variables
- `js/script.js` — mobile navigation and dynamic year
- `images/` — put your project screenshots and profile photo here

## Quick customization
Open `css/style.css` and edit the variables at the top:
- `--accent` — main accent color
- `--text` — main text color
- `--surface` — light section background
- `--dark` — dark sections
- `--max` — maximum content width

Then replace:
- `Joseph` and biography text
- GitHub URL
- email address
- project descriptions
- placeholder image sections with your actual images

## Running locally
You can simply open `index.html` in a browser, or use VS Code Live Server.

No framework or build process is required.
